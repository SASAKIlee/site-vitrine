## 🚀 Como Rodar Localmente

1. **Instalar dependências:**
   ```bash
   npm install
   ```

2. **Configurar variáveis de ambiente:**
   - Copie `.env.example` para `.env.local`
   - Adicione suas credenciais do Supabase

3. **Rodar o servidor:**
   ```bash
   npm run dev
   ```

4. **Acessar:** http://localhost:3000
